# kids-youtube-short-lp

ChatGPT・Picsart・CapCutで、子ども向けの3Dアニメ動画を作り、YouTubeショートに投稿するまでを、パソコンで解説する、Instagram特典配布LPです。
[lp-template](https://github.com/ryooh18-byte/lp-template) をもとに作成し、デザインと固定部分は [line-stamp-lp](https://github.com/ryooh18-byte/line-stamp-lp) にそろえています。

`index.html` 1ファイル（CSS・JS内蔵）＋ `assets/` で完結します。

## 内容

| 場所 | 内容 |
|---|---|
| はじめに | AIで作る動画を、おうち副業に（孫や娘にも見せられる、趣味と実益を兼ねた副業）。公開は簡単、収益には作業が必要、の一言 |
| こんな悩み | 悩み3つと、「これまで／AIに任せると」の表 |
| このガイドについて | 5ステップの流れ |
| STEP 1 | 用意するもの（パソコン・YouTubeチャンネル・ChatGPT・Picsart・CapCutパソコン版）。ChatGPTとCapCutは無料で始められる。Picsartで動画を作るには有料プランが必要（※2026年11月現在、新規登録だけではクレジットが0のことがある。プロプランの料金を、時点つきで書いている） |
| STEP 2 | 指示文①で、お話のアイデアを10個出し、番号を返信する |
| STEP 3 | 指示文②で、シーン1〜3の英語の指示文・ナレーション・BGMの案を作る |
| STEP 4 | Picsart（AI Playground）で、「動画」を選び、9:16・10秒・「下書き」オンで、10秒×3本を作って保存（ほかの動画AIでも使えることがある、の注意書きつき） → CapCutでつなぎ、自分の声のナレーション、オーディオ ライブラリのBGMを入れて書き出す |
| STEP 5 | YouTubeショートに投稿（「子ども向け」に設定）。収益化の条件（※2026年11月現在） |

## 確認した情報（2026年11月）

- 指示文①②は、ログインなしの無料ChatGPTで、台本どおりの流れ（①→「1番にします」→②）で動作を確認
- 収益化の条件・量産型のコンテンツ・子ども向け設定の影響：YouTubeヘルプ
- オーディオ ライブラリ：YouTube Studioの左のメニューから開ける。収益化した動画にも使える（YouTubeヘルプ）
- CapCutのパソコン版：無料でダウンロードでき、Windows・Macに対応（CapCut公式）
- Picsartの料金（2026-11-13に、料金ページで確認）：プロは、年間請求で月額1,699円、月次請求で月額2,429円。LPには、「※2026年11月現在」付きで、プロの料金を書いている。料金は変わるので、更新するときは、料金ページで確認し直す
- 2026-11-13：新しく登録したPicsartの無料アカウントは、残りクレジット数が0で、動画を作れなかった（ご本人の画面）。LPの「無料で始められます」を、有料プランが必要に直した
- 2026-11-13：Picsartの実際の画面（入力欄の左下の「動画」、上の小さな「VIDEO」は読み込みボタン、右下の「1080p｜16:9｜15秒」、「下書き」スイッチ）に、STEP 4を合わせた

## 固定部分

プロフィールリンク、特典バナー、お礼＋自己紹介、つなぎ文、締めのメッセージカード（相談会の一文つき）、フッターの免責、スマホ下部の固定ボタン、LINE誘導のリンク。いずれも line-stamp-lp と同じです。

## 画像・動画素材（`assets/`）

- `example-video.mp4`：「できあがりの例」の動画（10秒・音声つき・1280×720の横向き）。Geminiで、シーン1の指示文から作ったもの。ファイルの中には、Googleの作成元の記録（Content Credentials）と、目に見えない透かし（SynthID）が入っている。LPでは、動画AIで作った例とだけ書き、CSSで中央を縦型（9:16）に切り出して表示している（自動再生なし・全画面ボタンなし）
- `free-gift-banner.png`／`kumi-profile.png`：テンプレートの固定素材
